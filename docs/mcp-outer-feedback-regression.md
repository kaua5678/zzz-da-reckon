## 静态疑点（尚不把它当四条失败的唯一根因）

`runOuterLoop` 中 `curSig` 是跨轮可变变量，先参与 `sigRepeats`，随后才由本轮序列赋值。
因此第 k 轮判据实际比较的是 `signature[k-1]` 与 `signature[k-2]`，不是注释声明的
`signature[k]` 与 `signature[k-2]`。历史长度限制还改变了冷启动第二轮的退出机会。

同一块注释同时宣称 lag=1 和 lag=2 正确，并引用不存在的可行性守卫；不能把这些历史解释当现行契约。
需要把“本轮测量”“历史快照”“稳定/周期判断”的相位分清，并用真实管线和最小序列分别验证。
