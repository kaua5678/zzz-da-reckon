# docs/archive —— 一次性交接报告归档

本目录收的是**「某轮交接完成、读完即失效」的报告**：它们记录的是「当时怎么做的」，
不是「现在是什么」。判据 9（README §6 表 == 活文档）**不要求**本目录登记。

## 收录判据（三条都要满足）

1. **已完成**：报告里的任务已经落地，不存在「待办 / 阻塞点」仍需跟进。
2. **不含现役口径**：报告里的数值/映射/裁决**全部**已经在活代码（注释 / `@fact` / 测试）或活手册里有一份。
   有口径只在报告里 = **先搬进活手册，再归档**（例：`--shell-*`/`--brand-*`/`--dev-*` 令牌表已搬进 `docs/UI_THEME_GUIDE.md` §2.1）。
3. **没有活引用**：`grep -rl "docs/<文件名>" src scripts` 为空（活代码注释指向归档文件 = 把读的人引到死胡同）。

## 与 git 的关系

归档 ≠ 删除：文件仍在 git 里逐字保存，`git log -- docs/archive/<文件名>` 可查沿革。
**不要**把归档内容再「整理成新文档」——那是把问题挪个地方（AGENTS 规则 8）。

## 找东西

- 想知道某轮怎么做的 → `git log --grep="<关键词>"` 或直接读本目录。
- 想知道**现在**的存量/口径 → 永远看活代码 + `RATCHET_BURNDOWN`（`scripts/lib/guard-registries.mjs`）+ 活手册，**不要**读归档。
