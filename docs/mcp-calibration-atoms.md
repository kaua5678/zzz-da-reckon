## 0. 通用测量法（每个原子都用它）

**比值法**：同一个角色、同一招、同一个敌人，只改变**一个**因素，各打 N 次（N ≥ 5），取**非暴击**命中的伤害数字求中位数，再算两组的比值。
- 比值会把所有没改变的乘区全部约掉（等级系数、抗性、增伤……），所以**不需要知道完整公式**，只校验被改变的那一个乘区。
- 每条记录：配装快照（截图角色面板）、敌人名、招式名、N 个伤害数字、录像时间码。
- 误差预算：游戏里的伤害数字是取整后的整数，单次伤害 ≥ 1000 时，舍入误差小于 0.1%。**判据：|实测比值 − 引擎预测比值| ≤ 1%**，超出就要列入差异报告。

**录入格式**（将来放在 `src/calibration/atoms/<id>.json`，本卡不建目录）：

```json
{ "atom": "A1", "date": "YYYY-MM-DD", "gameVersion": "x.y",
  "setup": { "agent": "…", "move": "…", "enemy": "…", "build": "截图路径" },
  "groups": { "base": [1234, 1236], "variant": [1500, 1502] },
  "observedRatio": 1.2156, "engineRatio": 1.2160, "withinBudget": true }
```

## 2. 下一步（v2 的开工粒度）

1. 用户测完任意一个原子后，AI 做这几件事：
   - 录入 `src/calibration/atoms/<id>.json`，需要先建目录并在 README §6 登记本机制；
   - 写 `src/calibration/__tests__/atoms.test.ts`，读取 JSON，断言 `|observedRatio − engineRatio| ≤ 1%`；
   - engineRatio 用一次性探针从引擎算出，**不要手算**：构造与实测相同的配装与敌人，调用 `calcDirectDamage` 或 `calcAnomalyDamage` 两次取比值。
2. 超出预算的原子：写差异报告到 census，并**先改引擎口径再改数据**。A1 的具体做法是让引擎读 `basis`，参见 CC-96 的回退说明。
3. 原子与口径绑定（方向 E）：原子通过之后，在对应的 `@fact` 行追加 `验 src/calibration/atoms/<id>.json`。
