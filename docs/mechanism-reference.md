## 1. 能量学（第一期）

### 1.1 基础规则

- **能量上限**：所有角色统一 120 点
- **基础回能**：大部分角色 1.2 点/秒（= 0.02 点/帧，60fps）
- **特殊回能**：部分角色核心技提高基础回能（如柏妮思 1.56 点/秒，部分角色 1.0 点/秒）
- **闪能**：命破角色的能量系统，功能与能量完全一致，字段名不同（第一期未涉及，后续版本新增）

### 1.2 回能公式

```
能量获取 = 能量获得效率 × (能量自动恢复 × 时间 + 其他一次性获取)
能量自动恢复 = 基础回能 × (1 + 百分比加成) + 固定加成
```

- **百分比加成**：驱动盘/音擎的 `energyRegen`（是百分比加成，不是固定值）
- **固定加成**：音擎等提供的固定点/秒加成
- **获得效率**：独立乘区，最后提升

### 1.3 能量来源分类

| 来源 | 说明 |
|------|------|
| 能量自动回复 | 基础回能 × 时间，前台后台均可获得 |
| 攻击回能 | 招式固有的回能值（平A、强特等） |
| 怪物死亡掉落 | 固定数值 |
| 配装/邦布/技能特效 | 音擎、驱动盘、邦布等特效回能 |

### 1.4 前后台机制

- 前台/后台角色均可自动回能
- 全队接战状态统一：前台触发接战时后台同样触发
- 回能是连续平滑增加的（1.2/60 = 0.02/帧）

### 1.5 招式回能实测示例

| 角色 | 招式 | 回能 |
|------|------|------|
| 艾莲 | 普攻第一段 | ~0.68 |
| 艾莲 | 普攻完整一套 | ~9.79 |
| 猫又 | 普攻第一段 | ~0.62 |
| 猫又 | 普攻完整一套 | ~9.06 |
| 艾莲 | 巡游长按 | 5.98 |
| 艾莲 | 普通冲刺攻击 | 1.25 |
| 艾莲 | 闪避反击 | 3.87 |

> **计算器实现**：`resource.ts` 中 `calcBasicAttackRegenPerSec()` 从倍率表提取平A秒均回能。基础回能 1.2 来自角色数据 `energyRegen` 字段。

## 2. 喧响学2.0（第七期）

### 2.1 基础规则

- **喧响上限**：3000（等价 1 次终结技），未变化
- **存储机制**：2.0 起改为每个角色独立喧响条（1.0 为全队共用）
- **开局赠送**：每人 1000 点

### 2.2 喧响获取来源

| 来源 | 说明 |
|------|------|
| 动作（平A等） | 招式固有的喧响回复 |
| 技能 | 强特/连携/终结技等技能的喧响回复，2.0 统一为原来的 1.285 倍 |
| 伴随 | 队友释放招式时，其他角色获得该招式喧响的 50%（部分角色 52.5%） |
| 开场 | 每人 1000 点 |
| 特效 | 音擎/驱动盘等特效 |

### 2.3 特殊动作喧响奖励

| 动作 | 喧响奖励 |
|------|---------|
| 支援攻击（招架/弹刀） | 215/次 |
| 快速支援 | 20/次 |
| 失衡触发 | 20/次 |
| 部位破坏 | 20/次 |
| 连携 | 10/次 |

> **实现注记**：弹刀 215/闪反 10/连携 10/快支 20（闪避反击另有倍率表 `decibel_recovery` 数据行回复，10 为独立事件奖励）由 `calcSpecialActionBonus` 按槽位结算（个人全额 + 队友伴随 50%），与异常/紊乱/乱流奖励（`anomalyPool.perSlotBonus`）一起**参与终结技次数推导**（`ultimateCount = floor(total/3000)`，与界面喧响总览同口径）。失衡触发 20/次 的归属（每人/全队）无出处，暂未接入。

### 2.4 异常/紊乱喧响奖励（按怪物类型）

| 怪物类型 | 触发异常 | 触发紊乱 |
|---------|---------|---------|
| 首领 Boss | 170 | 85 |
| 精英怪物 | 125 | 65 |
| 普通怪物 | 35 | 15 |

### 2.5 终结技

- 消耗 3000 喧响（全游戏统一，仅 1 个角色 2000 暂不纳入）
- 释放不回复喧响（数据行无 `decibel_recovery`）
- 2.0 改为真时停
- 终结技招架回复从 3 点改为 1 点

### 2.6 2.0 相比 1.0 的更新

1. 喧响值独立（每角色自己的条）
2. 技能喧响收益统一 ×1.285
3. 伴随机制加入（队友获得 50%）
4. 终结技时停改为真时停
5. 终结技招架回复 3→1

> **计算器实现**：`resource.ts` 中 `DecibelSource` 类型记录各来源明细。`ULTIMATE_COST_DEFAULT = 3000`。特殊动作奖励在 `anomalyPool.ts` 的 `calcSpecialActionBonus()` 中计算，并经 `ResourceCalcConfig` 按槽位注入资源池（见 §2.3 实现注记）。

## 3. 击破学（第三期）

### 3.1 失衡值计算公式

```
单次技能累积失衡值 = 冲击力 × 失衡倍率 × 失衡抗性区 × 失衡值提升区 × 受到失衡值提升区
```

### 3.2 各乘区说明

| 乘区 | 来源 | 说明 |
|------|------|------|
| 冲击力（impact） | 角色基础冲击力 + 场内场外加成 | 独立乘区，线性影响 |
| 失衡倍率（daze） | 招式倍率表 `daze` row | 每个招式固定值 |
| 失衡抗性区 | 弱点 ×1.2，抗性 ×0.8，格挡 ×1.0 | 与伤害抗性、异常积蓄抗性独立 |
| 失衡值提升区 | 震星迪斯科4件套、击破角色技能、音擎等 | `(1 + stunBuildUpBonus/100)` |
| 受到失衡值提升区 | 物理异常[畏缩] +7.5%，持续10秒 | `(1 + enemyStunTakenBonus/100)` |

### 3.3 失衡抗性机制

- 弱点属性：失衡抗性区 = 1.2（积蓄更快）
- 抗性属性：失衡抗性区 = 0.8（积蓄更慢）
- 格挡（无属性）：失衡抗性区 = 1.0
- **与伤害抗性、异常积蓄抗性三者完全独立**

### 3.4 失衡条与连携

- 失衡条长度（bossStunValue）随怪物种类、等级、场景变化
- 示例：10级提尔锋 600，10级法布提约 3593，70级法布提约 8443
- 失衡次数 = floor(全队总失衡值 / bossStunValue)
- 连携次数 = 失衡次数 × 每次连携数（首领默认 3）

### 3.5 失衡易伤

| 怪物类型 | 失衡易伤 |
|---------|---------|
| 大部分怪物 | +50%（×1.5） |
| 一部分怪物 | +100%（×2.0） |
| 少部分怪物 | +25%（×1.25） |
- 莱卡恩、青衣可进一步提升该倍率

### 3.6 失衡时间

| 怪物类型 | 失衡时间 |
|---------|---------|
| 大部分 Boss | 12秒恢复 + 4秒进入 = 16秒 |
| 精英怪 | ~10秒 |
| 双子舞者 | ~7秒 |
- 0命莱特：+3秒
- 1命莱特：+5秒

### 3.7 喧响奖励

- 失衡触发：20 点/次
- 连携：10 点/次

### 3.8 物理异常[畏缩]

- 使敌人受到的失衡值 +7.5%
- 持续 10 秒
- 是「受到失衡值提升区」的唯一来源

> **计算器实现**：`stunPool.ts` 的 `calcPerHitStun()` 实现了完整的5乘区计算。`enemyStunTakenBonus` 来自物理异常[畏缩]。

## 4. 异常学（第五期）

### 4.1 异常积蓄上限公式

```
实际上限 = 基础值(3000) × boss系数 × 危局异常系数 × 累计系数 × 元素特殊系数
```

### 4.2 累计系数

- 每触发一次该属性异常，下一管上限 +2%（向下取整）
- 约等于 ×1.02^(已触发次数)
- 最多 1.02^9（第10管起不再增加）
- 因为向下取整，比精确值少个位数

### 4.3 元素特殊系数

| 元素 | 特殊规则 |
|------|---------|
| 冰/火/电/以太 | 无特殊，基础值 3000 |
| 物理 | 始终 ×1.2，基础值 3600 |
| 风 | 第1管 50%（1500），第2管 ~80-90%（2700），第3管起同冰火电 |

### 4.4 积蓄上限表（基础值 × 累计系数 × 元素特殊系数）

| 已触发次数 | 冰火电以太 | 风 | 物理 |
|-----------|-----------|---|------|
| 0 | 3000 | 1500 | 3600 |
| 1 | 3060 | 2700 | 3672 |
| 2 | 3121 | 3121 | 3745 |
| 3 | 3183 | 3183 | 3819 |
| 4 | 3246 | 3246 | 3895 |
| 5 | 3310 | 3310 | 3972 |
| 6 | 3376 | 3376 | 4051 |
| 7 | 3443 | 3443 | 4132 |
| 8 | 3511 | 3511 | 4214 |
| 9+ | 3581 | 3581 | 4298 |

### 4.5 累积阈值比较

因为每管上限不同（累计系数递增），不能用 `总积蓄值 ÷ 固定上限`。预计算累积阈值（前缀和）后比较：

```
threshold[0] = cap[0]                    // 达到第1管需要 3000
threshold[1] = cap[0] + cap[1]           // 达到第2管需要 6060
threshold[N] = Σ cap[0..N]              // 达到第N+1管

比较 totalBuildUp >= threshold[i] × boss系数 × 危局系数
找到最大的 i+1 即为触发管数
```

超过表中最大管数（10管）后，上限不再增加，用固定上限继续计算。

### 4.6 异常掌控与异常精通

| 属性 | 作用 | 公式中的位置 | 上限 |
|------|------|-------------|------|
| 异常掌控（anomalyMastery） | 影响异常积蓄速度 | `(1 + 掌控/100)` 作用于积蓄 | **无上限** |
| 异常精通（anomalyProficiency） | 影响异常伤害 | `(1 + 精通/100)` 作用于伤害 | **无上限** |

- 掌控数值通常 100-400+，/100 得到作用数值（300掌控 = 积蓄速度×4）
- 精通数值通常 100-700+，/100 得到作用数值（600精通 = 异常伤害×7）
- **NGA 公式帖中的上限是错误的，实际无上限**
- 精通仅影响异常伤害，不影响异常积蓄
- 掌控仅影响异常积蓄，不影响异常伤害

### 4.7 异常积蓄抗性

- 弱点属性：积蓄抗性 -20%（积蓄更快）
- 抗性属性：积蓄抗性 +20%（积蓄更慢）
- 与伤害抗性、失衡抗性三者独立

### 4.8 各属性异常效果

| 元素 | 异常名称 | 效果 |
|------|---------|------|
| 物理 | 强击/畏缩 | 畏缩使敌人受到失衡值 +7.5%，持续10秒 |
| 冰 | 冻结/碎冰 | 冻结后碎冰造成伤害 |
| 火 | 灼烧 | 持续火属性伤害 |
| 电 | 感电 | 持续电属性伤害 |
| 以太 | 侵蚀 | 持续以太属性伤害 |
| 风 | 风蚀 | 风化状态，30秒，提升风属性直伤 |

### 4.9 异常伤害公式

```
异常伤害 = 攻击力 × 异常倍率 × 增伤区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区 × 精通区 × 等级区 × 异常增伤区 × 异常暴击区
```

- 精通区 = `(1 + 异常精通/100)`
- 异常暴击区 = 默认1（部分角色可赋予异常暴击）

### 4.10 异常触发喧响奖励

- 首领 Boss：170 点/次
- 精英怪物：125 点/次
- 普通怪物：35 点/次

> **计算器实现**：`anomalyPool.ts` 实现了累积阈值比较、积蓄上限表、单次积蓄计算。`bossCoeff` 和 `anomalyCoeff` 从 `EnemyConfig` 获取。

## 5. 紊乱学（第六期）

### 5.1 触发条件

- 新异常覆盖老异常时触发紊乱
- 同属性异常可覆盖并触发紊乱
- 不同属性异常可连续触发多次紊乱
- 紊乱有独立 3 秒冷却

### 5.2 紊乱伤害公式

```
紊乱伤害 = 攻击力 × 倍率 × 增伤区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区 × 精通区 × 等级区 × 异常增伤区 × 异常暴击区
```

- **继承触发紊乱前的异常状态的所有乘区**（含属性抗性）
- 攻击力与倍率构成基础伤害区

### 5.3 各属性紊乱倍率

紊乱倍率由基础倍率 + 时间系数组成，T 为被覆盖异常的剩余时间（秒）：

| 被覆盖异常 | 紊乱倍率公式 | T=10最大倍率 |
|-----------|-------------|-------------|
| 畏缩（物理）/ 凛刃 | 450% + floor(T) × 7.5% | 525% |
| 霜寒（冰） | 450% + floor(T) × 7.5% | 525% |
| 灼烧（火） | 450% + floor(T/0.5) × 50% | 1450% |
| 感电（电） | 450% + floor(T) × 125% | 1700% |
| 侵蚀（以太）/ 玄墨 | 450% + floor(T/0.5) × 62.5% | 1700% |
| 烈霜（霜寒变体） | 600% + floor(T) × 75% | 2100% (T=20) |

> 注：玄墨同以太公式，凛刃同物理公式。烈霜持续20秒（雅专属），其余异常默认10秒。

### 5.4 紊乱伤害的异常质量与结算区

异常伤害分为「基础部分」（异常质量）和「结算部分」，两部分来自不同角色：

```
异常伤害 = 异常质量 × 结算区
```

**异常质量（基础部分，来自异常施加者）：**
```
异常质量 = 攻击力 × 倍率 × (1 + 普通增伤) × (1 + 异常精通) × 防御区[穿透率, 穿透值] × 等级区
```

**结算区（实时计算）：**
```
结算区 = 减防 × 无视防御 × 减抗 × 无视抗性 × 异常增伤 × 异常暴击 × 减易伤 × 失衡易伤
```

| 异常类型 | 异常质量 | 属性抗性 | 伤害性质（异常增伤/暴击） | 结算区来源 |
|---------|---------|---------|------------------------|-----------|
| 异放 | 继承原异常全部 | 继承 | 继承 | 触发者 |
| 紊乱 | 继承原异常 | 继承 | **不继承** | 触发者 |
| 乱流 | 非风角色提供 | 非风属性 | 继承非风性质 | 维琳娜(风角色) |

### 5.5 紊乱与失衡

- 异常伤害本身**不产生**失衡
- 紊乱**可以**产生失衡

### 5.6 月城柳极性紊乱

- 特殊紊乱机制
- 基础倍率固定 100%（低于常规紊乱）
- 与自身精通呈平方关系

### 5.7 紊乱次数计算

紊乱需要不同属性异常交替覆盖触发（同属性不触发紊乱）。计算器使用通用公式估算最大紊乱次数：

```
紊乱次数 = min(sum - 1, 2 × (sum - max))
```

- sum = 所有元素触发次数之和
- max = 最大元素触发次数
- sum-1 = 序列最大覆盖次数（最后一个异常不被覆盖）
- 2×(sum-max) = 非多数元素能分隔的多数元素次数
- 验证：6火10电 → sum=16, max=10 → min(15, 12)=12次（6次电紊乱+6次火紊乱）
- 验证：4火4电 → sum=8, max=4 → min(7, 8)=7次
- 默认不浪费低次数的异常：公式自动最大化紊乱次数

> 注：旧公式 `2 × min(floor(sum/2), sum-max)` 在3+元素且无单一元素过半时多算1次（如4火4电算出8但实际最多7）。

### 5.8 异常状态覆盖率

```
总DoT时间 = Σ(各元素触发次数 × 该元素默认持续时间)
有效DoT时间 = 总DoT时间 - boss无敌时间
覆盖率 = 有效DoT时间 / 总战斗时间
```

各属性默认持续时间：火/电/以太/物理/冰 = 10秒，烈霜 = 20秒，风化 = 30秒

物理异常（畏缩）覆盖率用于增幅失衡值：实际增幅 = 7.5% × 覆盖率

> **紊乱T值说明**：紊乱伤害计算中，每个元素的T使用该元素自身的默认持续时间（如烈霜T=20s），不使用平均值。角色专属延时（如雅20秒烈霜）只计入自己的紊乱T，不分给别人。当有风属性时不计算紊乱（触发乱流）。

### 5.9 紊乱喧响奖励

| 怪物类型 | 紊乱奖励 |
|---------|---------|
| 首领 Boss | 85 |
| 精英怪物 | 65 |
| 普通怪物 | 15 |

### 5.10 乱流喧响奖励

- 首领 Boss：85 点/次
- 触发者归属：风底属性提供者
- 伴随获得：另外两个队友各获得一半，即 42.5 点/次

> **计算器实现**：`anomalyPool.ts` 实现了完整的紊乱次数计算、紊乱/乱流伤害计算（含异常质量与结算区分离）、异常覆盖率计算，以及异常/紊乱/乱流喧响奖励分配。紊乱倍率公式存储在 `DISORDER_FORMULAS` 表中，乱流倍率公式存储在 `TURBULENCE_FORMULAS` 表中。

## 6. 穿透防御学（第八期）

### 6.1 防御区公式

```
防御区 = 794 / (有效防御 + 794)
```

- 794 是等级基数（60级）
- 60级首领防御 953 → 防御区 = 794/(953+794) = 0.4545

### 6.2 防御降低机制

| 机制 | 说明 | 
|------|------|
| 穿透率（penRatio） | 按百分比降低防御 | 
| 穿透值（penFlat） | 按固定值降低防御 | 
| 减防（enemyDefReduction） | 按百分比降低防御 |
| 无视防御 | 和减防加算，虽然名字不同，但游戏代码使用的减防字段 |

```
有效防御 = 怪物防御 × (1 - 穿透率/100) × (1 - 减防/100-无视防御/100) - 穿透值
有效防御 = max(0, 有效防御)
```

### 6.3 满级Boss 防御值表

| boss类型 | 防御值 |
|------|--------|
| 正常boss | 953 | 
| 高防boss（彷徨猎手） | 1588 | 
| 低防boss | 476 | 

### 6.4 抗性区

```
抗性区 = 1 - 有效抗性/100
有效抗性 = 怪物抗性 - 抗性降低 - 抗性无视（不设下限，可负）
```

- **抗性区不设上限**：减抗超过怪物抗性后有效抗性为负，抗性区 > 1（弱点化，线性提升；计算器 `calcResistanceMultiplier` 与此一致，弱点 -20% 即抗性区 1.2）。
- **boss抗性有偏好**：boss可以同时拥有火抗和冰弱点，每种元素抗性独立
- 弱点属性：抗性 -20%（抗性区 = 1.2）
- 抗性属性：抗性 +20%（抗性区 = 0.8）
- 减抗（抗性降低）是全局debuff，对所有人生效
- 与防御区不同：防御只有自身一种，但抗性可以有多种偏好

> **异常/紊乱/乱流抗性**：异放、紊乱、乱流的抗性乘区中，基础抗性 ×0.5（减半），再减去全局减抗。计算器使用按元素抗性查找（`enemyResistances[element]`），而非单一值。


### 6.5 易伤区

```
易伤区 = 1 + 易伤/100
```

### 6.6 命破角色贯穿机制

- 命破角色可无视 100% 防御（贯穿）
- 贯穿伤害不受防御区影响
- 但仍受抗性区、易伤区影响
- 比普通角色多一个独立乘区：贯穿增伤

> **计算器实现**：`damage.ts` 中防御区通过公式动态计算。`penDmgBonus` 用于命破角色的贯穿增伤。

## 7. 秽盾学（第九期）

### 7.1 秽盾概念

- 秽盾是怪物的护盾机制
- 开启后获得高额防御与减伤加成
- 失衡条被替换为秽盾条
- 失衡值最高积累至 99.5% 后停止
- 需先破除秽盾才能将怪物打入失衡

### 7.2 秽盾增益

| 增益 | 数值 |
|------|------|
| 基础防御增加 | +80% |
| 减伤 | 25%（贯穿伤害同样生效） |

- 示例：秽息司祭 Lv1 防御从 60 等效为 108，防御区从 0.4545 降至 0.3164（约原来的 70%）（防御区需要具体算，不同穿透情况的防御区不能一概而论）

### 7.3 破盾奖励

| 盾类型 | 破盾奖励 |
|--------|---------|
| 秽盾 | 全队回复 50% 能量（含闪能）= 60 点；怪物受到总血量 15% 伤害（危局 3%） |
| 能量盾 | 回复 30 点能量（不给命破角色加闪能） |

### 7.4 秽盾量与动作时间

```
动作时间（秒） = 秽盾量 / 100
```

不同招式类型的动作时间修正（用户整理，非文章直接给出）：

| 招式类型 | 时间公式 |
|---------|---------|
| 一般招式（含连续弹刀、快速支援） | 秽盾 / 100 |
| 闪避反击 | 秽盾 / 100 - 1.5 |
| 轻重弹刀（Defensive Assist #1/#2） | 秽盾 / 100 - 2.5 |
| 终结技（大招） | 秽盾 / 100 - 5 |

### 7.5 招式对秽盾的削减倍率

| 招式类型 | 削减倍率（t为动作招式） |
|---------|---------|
| 一般攻击 | 100×t |
| 闪避反击 | 100×t+150 |
| 轻重弹刀 | 100×t+250 |
| 终结技 | 100×t+500 |

> **计算器实现**：`resource.ts` 中 `shieldCount` 控制秽盾数量，每个破后送 60 点能量/闪能。`energyShield` 控制能量盾数量，每个破后送 30 点能量。动作时间存储在 `SkillMove.actionTime`。

## 8. 风属性（第十期）

### 8.1 风化状态

- 打满风异常积蓄后触发
- 一次性风化伤害（基础倍率 1250%）
- 施加持续 30 秒的风化状态
- 期间风属性直接攻击伤害提升

### 8.2 浸染

- 风化状态下，首次受其他属性伤害时触发
- 染色效果：同系数直伤提升
- 浸染属性会随乱流属性转换

### 8.3 乱流

- 风化与其他属性异常叠加时触发
- 范围伤害，继承非风属性的异常质量、属性、伤害性质
- **风化状态下不触发常规紊乱，触发乱流**
- 乱流可多次触发

### 8.4 乱流伤害公式

```
乱流伤害 = 非风属性异常质量 × 乱流倍率 × 结算区
```

- 乱流倍率随非风异常剩余时间 T 递增
- T = 非风异常剩余时间（风化不被覆盖，T通常可吃满默认时间）
- 有风属性时DoT伤害归零（被乱流吞了），不触发紊乱
- 乱流3秒CD；单次30秒风化可容纳10次，计算器按多次风化窗口合并，不封顶

各属性乱流倍率公式（T代入默认时间时：火/电/以太=10s，烈霜=20s）：

| 非风异常 | 乱流倍率公式 | T=10最大倍率 | T=20最大倍率 |
|---------|-------------|-------------|-------------|
| 物理 | 800% + floor(T) × 7.5% | 875% | - |
| 冰 | 1300% + floor(T) × 7.5% | 1375% | - |
| 火 | 900% + floor(T/0.5) × 50% | 1900% | - |
| 电 | 650% + floor(T) × 125% | 1900% | - |
| 以太 | 650% + floor(T/0.5) × 62.5% | 1900% | - |
| 烈霜 | 0% + floor(T) × 75% | - | 1500% |

> 注：火/电/以太倍率高因为乱流吞了DoT伤害；冰/物理/烈霜的强击倍率713%、冻结倍率500%没被吞，乘区不同不能直接相加。

### 8.5 风化被极性紊乱

- 基础倍率固定 100%
- 低于常规紊乱

### 8.6 维琳娜特殊机制

- 风化系数：10%
- 一命效果：
  - 乱流：无视全属性抗性
  - 风化/异放：无视风属性抗性
- 其他风属性角色的风化系数待实测

> **计算器实现**：`anomalyPool.ts` 中 `BUILDUP_CAP_TABLE.wind` 实现了风的特殊积蓄上限。`TURBULENCE_FORMULAS` 存储了各属性乱流倍率公式。有风属性时自动切换为乱流计算模式，DoT归零。
