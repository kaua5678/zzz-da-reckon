## 1. 能量学（第一期）

- **能量上限**：所有角色统一 120 点；**基础回能**：大部分角色 1.2 点/秒（= 0.02 点/帧，60fps）；部分角色核心技提高基础回能（如柏妮思 1.56 点/秒）。
- **闪能**：命破角色的能量系统，功能与能量完全一致，字段名不同。
- **回能公式**：`能量获取 = 能量获得效率 × (能量自动恢复 × 时间 + 其他一次性获取)`；`能量自动恢复 = 基础回能 × (1 + 百分比加成) + 固定加成`。百分比加成 = 驱动盘/音擎 `energyRegen`（百分比，非固定值）；获得效率为独立乘区最后提升。
- 前台/后台角色均可自动回能；全队接战状态统一（前台触发时后台同样触发）；回能连续平滑增加。
- **实现唯一事实源**：`src/core/resource.ts#calcBasicAttackRegenPerSec`（平A秒均回能从倍率表提取）与 `calcEnergySource`；120/1.2 默认值见 `src/types/catalog.ts` 的 `energyRegen`/`energyMax` 字段注释。招式逐拔回能实测值（艾莲普攻首段 0.68 / 整套 9.79、猫又 0.62 / 9.06 等）即 catalog 倍率表 `energy_recovery` 行，本档不再抄。

## 2. 喧响学2.0（第七期）

- **上限**：3000（等价 1 次终结技）；2.0 起每个角色独立喧响条（1.0 为全队共用）；开局每人赠 1000 点。
- **获取来源**：动作（平A等）/技能（2.0 统一为原来的 1.285 倍）/伴随（队友招式时其他角色获得该招式喧响的 50%，部分角色 52.5%）/开场/特效（音擎驱动盘等）。
- **特殊动作奖励**：支援攻击（招架/弹刀）215/次、快速支援 20/次、失衡触发 20/次、部位破坏 20/次、连携 10/次。
- **终结技**：消耗 3000 喧响（全游戏统一，仅 1 个角色 2000 暂不纳入）；释放不回复喧响（数据行无 `decibel_recovery`）；2.0 改为真时停；终结技招架回复 3→1。
- **实现唯一事实源**：`ULTIMATE_COST_DEFAULT = 3000`（`src/data/resourceDefaults.ts`，`src/core/resource.ts` re-export）；弹刀 215 = `src/core/anomalyPool.ts#PARRY_DECIBEL_BONUS`；连携/闪反 10、快支 20 与伴随 50% 由 `calcSpecialActionBonus` 按槽位结算（个人全额 + 队友伴随 50%），与异常/紊乱/乱流奖励（`anomalyPool.perSlotBonus`）一起参与终结技次数推导（`ultimateCount = floor(total/3000)`）。失衡触发 20/次 的归属（每人/全队）无出处，暂未接入。

## 3. 击破学（第三期）

- **失衡值公式**：`单次技能累积失衡值 = 冲击力 × 失衡倍率 × 失衡抗性区 × 失衡值提升区 × 受到失衡值提升区`。失衡倍率 = 招式倍率表 `daze` 行；冲击力独立乘区线性影响。
- **失衡抗性区**：弱点 ×1.2 / 抗性 ×0.8 / 格挡（无属性）×1.0，与伤害抗性、异常积蓄抗性**三者完全独立**。
- **失衡值提升区** = `(1 + stunBuildUpBonus/100)`（震星迪斯科4件套、击破角色技能、音擎等）；**受到失衡值提升区** = `(1 + enemyStunTakenBonus/100)`，唯一来源是物理异常[畏缩] +7.5%（持续10秒）。
- 失衡条长度（bossStunValue）随怪物种类/等级/场景变化；失衡次数 = floor(全队总失衡值 / bossStunValue)；连携次数 = 失衡次数 × 每次连携数（首领默认 3）。
- **失衡易伤**：大部分怪物 +50%、一部分 +100%、少部分 +25%；莱卡恩、青衣可进一步提升该倍率。
- **失衡时间**：大部分 Boss 12秒恢复 + 4秒进入；精英怪 ~10秒；双子舞者 ~7秒；0命莱特 +3秒 / 1命 +5秒。
- **实现唯一事实源**：`src/core/stunPool.ts#calcPerHitStun`（5 乘区 + 畏缩 `7.5 × physicalFlinchCoverageRate`，`enemyStunTakenBonus` 来自畏缩）。逐 boss 的失衡值/失衡易伤/失衡时间数值在 `public/static/boss-presets.json`（`monster.stunVuln`、`monster.stunTime`、`phases[].stunValue`），本档不再抄示例数值。

## 4. 异常学（第五期）

- **积蓄上限公式**：`实际上限 = 基础值(3000) × boss系数 × 危局异常系数 × 累计系数 × 元素特殊系数`。
- **累计系数**：每触发一次该属性异常下一管 +2%（向下取整，≈ ×1.02^n），最多 1.02^9（第10管起不再增加）；因向下取整比精确值少个位数。
- **元素特殊系数**：冰/火/电/以太无特殊（基础 3000）；物理始终 ×1.2（3600）；风第 1 管 1500（50%）、第 2 管 2700（90%）、第 3 管起同冰火电。
- **累积阈值比较**：每管上限递增，不能用 `总积蓄值 ÷ 固定上限`——预计算前缀和阈值后比较（`threshold[N] = Σ cap[0..N]`，与 boss系数×危局系数相乘后取达到的最大管数）；超过 10 管后用固定上限继续。
- **实现唯一事实源**：`src/core/anomalyPool/helpers.ts#BUILDUP_CAP_TABLE`（逐管上限表）+ `BUILDUP_THRESHOLD_TABLE`（前缀和阈值表）+ `MAX_CAP_INDEX`；单次积蓄与 `bossCoeff`/`anomalyCoeff` 在 `src/core/anomalyPool.ts`（输入来自 `EnemyConfig`）。
- **口径纠正**：异常掌控（积蓄乘区 `(1 + 掌控/100)`）与异常精通（异常伤害乘区 `(1 + 精通/100)`）**均无上限**——NGA 公式帖中的上限是错误的；精通仅影响异常伤害、掌控仅影响异常积蓄。掌控常见 100-400+、精通常见 100-700+。
- **异常积蓄抗性**：弱点属性 -20%（积蓄更快）/ 抗性属性 +20%（更慢），与伤害抗性、失衡抗性独立。

## 5. 紊乱学（第六期）

- **触发条件**：新异常覆盖老异常时触发紊乱；同属性异常可覆盖并触发；不同属性可连续触发多次；紊乱有独立 3 秒冷却。异常伤害本身**不产生**失衡，紊乱**可以**。
- 各属性紊乱倍率（基础倍率 + 时间系数）、乱流倍率、异常默认持续时间（烈霜 20s / 风化 30s / 其余 10s）的**唯一事实源** = `src/core/anomalyPool/helpers.ts#DISORDER_FORMULAS`、`TURBULENCE_FORMULAS`、`ANOMALY_DURATION`。紊乱 T 用该元素自身默认持续时间（角色专属延时只计入自己的紊乱 T，不分给别人）；有风属性时不计算紊乱（触发乱流）。
- **紊乱次数**：`min(sum - 1, 2 × (sum - max))`（sum = 各元素触发次数和，max = 最大元素次数；实现唯一事实源 = `src/core/anomalyPool.ts` 的紊乱次数公式与注释）。**否决记录**：旧公式 `2 × min(floor(sum/2), sum-max)` 在 3+ 元素且无单一元素过半时多算 1 次（4火4电算出 8、实际最多 7）→ 已否决，勿回退。
- **异常状态覆盖率**：`覆盖率 = (总DoT时间 - boss无敌时间) / 总战斗时间`；物理畏缩覆盖率用于增幅失衡值（实际增幅 = 7.5% × 覆盖率）。实现唯一事实源 = `src/core/anomalyPool.ts` 覆盖率计算。
- **月城柳极性紊乱（2026-09-14 按代码口径改写）**：倍率 = **原紊乱伤害的比例**——C0 = 15%；影画2 = 20% + 每额外突刺 15%（上限 2 次）；影画6 提升上限至 4 次；触发次数 ≈ 强特次数。唯一事实源 `src/mechanics/agents/yanagi.ts:35`（`YANAGI_POLAR_RATIO_C0` 等常量）。旧档「基础倍率固定 100%、与自身精通呈平方关系」的表述与实现不一致，已按实现改写（如需改口径先改 yanagi.ts）。

### 5.4 紊乱伤害的异常质量与结算区

异常伤害分为「基础部分」（异常质量）和「结算部分」，两部分来自不同角色：

```
异常伤害 = 异常质量 × 结算区
```

**异常质量（基础部分，来自异常施加者）：**
```
异常质量 = 攻击力 × 倍率 × (1 + 普通增伤) × (1 + 异常精通) × 防御区[穿透率, 穿透值] × 等级区
```

**结算区（实时计算）：**
```
结算区 = 减防 × 无视防御 × 减抗 × 无视抗性 × 异常增伤 × 异常暴击 × 减易伤 × 失衡易伤
```

| 异常类型 | 异常质量 | 属性抗性 | 伤害性质（异常增伤/暴击） | 结算区来源 |
|---------|---------|---------|------------------------|-----------|
| 异放 | 继承原异常全部 | 继承 | 继承 | 触发者 |
| 紊乱 | 继承原异常 | 继承 | **不继承** | 触发者 |
| 乱流 | 非风角色提供 | 非风属性 | 继承非风性质 | 维琳娜(风角色) |

## 6. 穿透防御学（第八期）

- **防御区**：`防御区 = 794 / (有效防御 + 794)`，794 是 60 级等级基数；`有效防御 = max(0, 怪物防御 × (1 - 穿透率/100) × (1 - 减防/100 - 无视防御/100) - 穿透值)`。「无视防御」与减防使用同一字段、加算（名字不同但游戏代码用减防字段）。
- **抗性区**：`抗性区 = 1 - 有效抗性/100`；`有效抗性 = 怪物抗性 - 抗性降低 - 抗性无视`，**不设下限**（可为负 → 抗性区 > 1，弱点化线性提升）。boss 抗性可有偏好（同时火抗+冰弱点，每种元素独立）；弱点 -20%（区 1.2）/ 抗性 +20%（区 0.8）；减抗是全局 debuff 对所有人生效。**异常/紊乱/乱流抗性**：基础抗性 ×0.5（减半）后再减全局减抗，按元素抗性查找（`enemyResistances[element]`）。
- **易伤区**：`易伤区 = 1 + 易伤/100`。
- **命破角色贯穿**：可无视 100% 防御；贯穿伤害不受防御区影响，但仍受抗性区、易伤区；另多一个独立乘区（贯穿增伤）。
- **实现唯一事实源**：`src/core/damage.ts`（`LEVEL_COEFF_60 = 794`、防御区公式、`calcResistanceMultiplier`、贯穿 `penDmgBonus`/`sheerDmgBonus`）与 `src/core/anomalyPool/helpers.ts`（异常侧防御区内联实现）。逐 boss 防御值在 `public/static/boss-presets.json` `defense` 字段（正常 953 / 高防 1588 / 低防 476），本档不再抄表。

## 7. 秽盾学（第九期）——未建模理论存量

### 7.1 秽盾概念

> ⚠ **口径纠正（用户 2026-09-13）：秽盾 ≠ 无敌时间**。秽盾期间怪物**可被攻击**（代理人能通过攻击削减[秽盾]），
> 只是获得高额防御/减伤/抗打断且不失衡。**不要把秽盾秒数填进引擎的 `invincibleTime`**（那是真无敌，
> 转阶段动画那类完全不可攻击的时间）——那会凭空砍掉可打时间。引擎侧边界见 `src/core/effectiveTime.ts`
> 的 `@fact engine:time/无敌≠秽盾` 与 `docs/ENGINE_PIPELINE_GUIDE.md` 的无敌时间口径段。
> 本计算器**尚未建模**秽盾本体（四通道：防御/减伤乘区、削盾量、破盾回能/净除伤害），
> 挂账见 `docs/MECHANICS_IMPLEMENTATION.md` §3.05 与 check-guards 的 DEBT_REGISTRY。
> **挂账与销号口径以 `scripts/check-guards.mjs` DEBT_REGISTRY 的 `src/core/effectiveTime.ts:秽盾机制`
> 条目为准**（本节以下数值为理论参考，落地以该专项立项的判据为准，勿在本档维护）。

- 秽盾是怪物的护盾机制
- 开启后获得高额防御与减伤加成
- 失衡条被替换为秽盾条
- 失衡值最高积累至 99.5% 后停止
- 需先破除秽盾才能将怪物打入失衡

## 8. 风属性（第十期）

- **风化**：打满风异常积蓄后触发；一次性风化伤害（基础倍率 1250%）；施加持续 30 秒的风化状态；期间风属性直接攻击伤害提升。
- **浸染**：风化状态下首次受其他属性伤害时触发，染色效果（同系数直伤提升）；浸染属性随乱流属性转换。
- **乱流**：风化与其他属性异常叠加时触发；范围伤害，继承非风属性的异常质量、属性、伤害性质；**风化状态下不触发常规紊乱，触发乱流**；可多次触发（3 秒 CD；单次 30 秒风化可容纳 10 次，计算器按多次风化窗口合并不封顶）。有风属性时 DoT 伤害归零（被乱流吞了）。
- **实现唯一事实源**：`src/core/anomalyPool/helpers.ts#TURBULENCE_FORMULAS`（各属性乱流倍率公式）+ `BUILDUP_CAP_TABLE.wind`（风特殊积蓄上限）；有风属性时自动切换乱流计算模式、DoT 归零（`src/core/anomalyPool.ts`）。乱流喧响触发者归属风底属性提供者，队友按 50% 伴随获得。

### 8.5 风化被极性紊乱

- 基础倍率固定 100%，低于常规紊乱。

### 8.6 维琳娜特殊机制（待实测，未建模存量）

- 风化系数：10%
- 一命效果：
  - 乱流：无视全属性抗性
  - 风化/异放：无视风属性抗性
- 其他风属性角色的风化系数待实测。

## 9. 接战状态（第四期）

### 9.1 状态分类

| 状态 | 说明 |
|------|------|
| 脱战状态 | 未进入战斗 |
| 伪接战状态 | 部分战斗触发 |
| 短接战状态 | 短时间战斗 |
| 长接战状态 | 持续战斗 |

### 9.2 前后台机制

- 前台/后台角色均可自动回能
- 全队接战状态统一
- 前台触发接战状态时后台同样触发
- 简的专武「淬锋钳刺」有特定触发规则
